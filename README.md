# Sorrel Aesthetics — Med Spa Website

An unhurried, luxury medical aesthetic practice website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

![Sorrel Aesthetics Preview](public/images/hero.jpg)

## ✨ Features

- **Framer Motion Animations**:
  - Smooth page transitions with `AnimatePresence`.
  - Floating pill active navigation indicator.
  - Interactive consultation timeline step walkthrough.
  - Smooth collapsible FAQs accordion.
  - Subtle image and card lift interactions.
- **Interactive Multi-Step Booking Wizard**: 5-step consultation booking flow with treatment selection, provider picker, date/time scheduling, and confirmation summary.
- **Personalized Treatment Cost Estimator**: Real-time slider and counter calculator with 10% Swann Avenue Club membership discount toggle.
- **Editorial Journal Reader**: Modal article reader for medical aesthetics essays.
- **Comprehensive Sections**:
  - Hero with value propositions and clinic overview
  - 8 Common Aesthetic Concerns catalog
  - 60-Minute First Visit protocol breakdown
  - Full Treatment Menu with transparent per-unit pricing
  - Clinical Provider profiles and Dr. Philippa Delacorte, MD oversight
  - Location, clinic hours, and interactive contact actions

## 🛠️ Tech Stack

- **Framework**: React 18 / 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Cormorant Garamond & Inter

## 🚀 Getting Started

### Prerequisites

Ensure [Node.js](https://nodejs.org/) (v18 or higher) is installed on your computer.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
